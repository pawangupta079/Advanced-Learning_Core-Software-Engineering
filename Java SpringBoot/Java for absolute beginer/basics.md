# 1. Introduction to Java

Java is a high-level, object-oriented, class-based programming language developed by Sun Microsystems in 1995.

Today Java is owned and maintained by Oracle.

Java is widely used for:

- Enterprise Applications
- Banking Software
- ERP Systems
- Spring Boot Applications
- Android Development
- Cloud Applications
- Microservices
- Big Data Systems

Examples:

- Amazon
- Netflix
- Uber
- LinkedIn

all use Java in many of their backend services.

# 3. Why Java Was Created

Before Java:

```text
One program
↓
One Operating System
```

Programs were platform dependent.

Java introduced:

```text
Write Once, Run Anywhere
```

Meaning:

```text
Code Once
↓
Compile Once
↓
Run Anywhere JVM Exists
```

---

```text

Run Anywhere
```

# 7. JVM Internal Architecture

```text
Class Loader
     |
Execution Engine
     |
Memory Areas
```

---

## Class Loader

Loads classes into memory.

---

## Execution Engine

Executes bytecode.

Contains:

### Interpreter

Reads line by line.

### JIT Compiler

Converts frequently executed code into machine code.

Improves performance.

---

# 8. Memory Areas Inside JVM

```text
JVM Memory
│
├── Method Area
├── Heap Area
├── Stack Area
├── PC Register
└── Native Method Stack
```

---

## Heap

Stores:

- Objects
- Arrays

Example:

```java
Student s = new Student();
```

Object created in Heap.

---

## Stack

Stores:

- Local Variables
- Method Calls

Example:

```java
int age = 25;
```

Stored inside Stack.

---

## Method Area

Stores:

- Class Information
- Static Variables
- Metadata

# 30. Important Interview Questions

## What is Java?

Java is an Object-Oriented, Platform Independent Programming Language.

---

## Why Java is Platform Independent?

Because Java code executes on JVM rather than directly on OS.

---

## Difference Between JDK JRE JVM?

### JDK

Development Kit

### JRE

Runtime Environment

### JVM

Bytecode Execution Engine

---

## What is Bytecode?

Compiled Java Code.

```text
.class File
```

---

## Difference Between Stack and Heap?

### Stack

Stores:

- Local Variables
- Method Calls

### Heap

Stores:

- Objects
- Arrays

---

## What is Garbage Collection?

Automatic removal of unused objects from Heap Memory.
